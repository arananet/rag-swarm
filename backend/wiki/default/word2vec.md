# Word2Vec

Word2Vec is a neural network-based algorithm for generating text embeddings. It takes in a dataset and produces a vector representation of each word in the dataset.

Word2Vec uses a neural network to predict the context words given a target word. The resulting vector representation of the target word is used as the text embedding.

Word2Vec is a popular algorithm for generating text embeddings because it is easy to implement and can handle large datasets.
